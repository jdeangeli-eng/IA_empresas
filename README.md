📌 Características Principales
Stack Dual Integrado:
Google AI Stack: Gemini, AppSheet (No-Code) y Looker Studio.
Microsoft Power Suite: M365 Copilot, Power Apps y Power BI.
Componentes Interactivos:
Acordeón modular: Despliegue de los 6 ejes temáticos del programa en JavaScript liviano.
Captura de Leads y Enrutamiento a WhatsApp: Formulario inteligente que compila los datos del prospecto (Nombre, Empresa, Desafío) y genera una URL precompletada hacia el WhatsApp del Asesor Académico (Jorge De Angeli).
Diseño Moderno & Dark Mode: Paleta emerald/cyan/dark slate inspirada en plataformas tech, optimizada con Tailwind CSS y efectos glassmorphism.
Full Responsive: Perfectamente adaptada a dispositivos móviles, tablets y monitores de alta resolución.
🛠️ Tecnologías Utilizadas
HTML5 & CSS3 (Estructura y estilos semánticos)
Tailwind CSS v3 (Vía CDN con configuración personalizada de temas y efectos glow)
FontAwesome 6 (Iconografía técnica y comercial)
Google Fonts: Plus Jakarta Sans & Inter
JavaScript (Vanilla): Gestión de estados de acordeón y cálculo/redirección de WhatsApp.

🚀 Cómo Implementar o Alojar
Clona o descarga el repositorio en tu máquina local.
Asegúrate de tener el archivo indexado como index.html.
Para publicar en línea de forma gratuita:
GitHub Pages: Sube el archivo a un repositorio público y activa GitHub Pages desde Settings > Pages.
Vercel / Netlify: Sube la carpeta o conecta el repositorio para un despliegue inmediato con certificado SSL automático.
